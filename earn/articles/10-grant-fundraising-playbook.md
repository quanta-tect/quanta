## Step 3: Write a Killer Proposal

### The Template

```markdown
# [Project Name] — Grant Application

## One-Line Description
[What you built in 10 words or less]

## Problem
[1-2 sentences on the problem you solve]

## Solution
[1-2 sentences on your approach]

## What's Built
- [x] Feature 1
- [x] Feature 2
- [x] Feature 3

## Test Coverage
- [x] 141+ tests passing
- [x] Security audit complete

## Use of Funds
| Item | Amount |
|------|--------|
| Security audit | $30,000 |
| Mainnet deployment | $20,000 |
| Dashboard MVP | $15,000 |
| SDK publish | $10,000 |
| Marketing | $30,000 |
| **Total** | **$105,000** |

## Timeline
- Month 1: Mainnet deployment
- Month 2: Dashboard MVP
- Month 3: SDK publish + marketing

## Links
- GitHub: [link]
- Demo: [link]
- Docs: [link]
```

### What Makes a Proposal Win

1. **Show, don't tell** — Deployed code > whitepaper
2. **Quantify impact** — "141 tests" > "thoroughly tested"
3. **Be specific with funds** — Line items > "operational costs"
4. **Show traction** — GitHub stars, Discord members, testnet users
5. **Align with their mission** — Base wants Base builders

### What Gets Rejected

1. No working code
2. Vague use of funds
3. No test coverage
4. Copy-paste proposals
5. Asking too much for too little

## Step 4: Build in Public

Grant committees love transparency:

```
Week 1: "Just deployed 4 contracts on Base Sepolia"
Week 2: "Added 50+ security tests, all passing"
Week 3: "Slither audit complete — 0 critical findings"
Week 4: "TypeScript SDK v1.0 published to npm"
```

Post updates on:
- Twitter/X
- Discord
- GitHub commits

## Step 5: Follow Up

After applying:
1. **Week 1**: Confirmation email
2. **Week 2**: Follow-up with GitHub link
3. **Week 3**: Share any progress/updates
4. **Month 2**: Polite reminder if no response

## Common Mistakes

1. **Applying too early** — Build first, apply second
2. **Being vague** — "Build a DeFi protocol" loses to "AI agent payment channels"
3. **Ignoring requirements** — Follow their template exactly
4. **Not following up** — 80% of funded projects followed up
