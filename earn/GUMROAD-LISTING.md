### What is Web3 Gig Finder?

A CLI tool that helps Web3/blockchain developers find freelance jobs, grant programs, and audit contests — all in one place.

### Features

🔍 **Smart Job Search**
- 24+ curated Web3 job listings
- Filter by skill: Solidity, Rust, TypeScript, AI, Python
- Sort by pay rate ($80-$280/hr)

💰 **Grant Programs**
- 8 active grant programs ($5K-$500K)
- Base, Optimism, Arbitrum, Gitcoin, Ethereum Foundation
- Direct links to apply

🛡️ **Audit Contests**
- Code4rena, Sherlock, Immunefi, Hats.finance
- Prize pools: $1K-$10M
- Duration and skill requirements

📝 **Cover Letter Generator**
- One-click cover letter templates
- Customizable for any Web3 job
- Professional formatting

📊 **Market Statistics**
- Top skills by demand
- Average pay rates
- Export to CSV/JSON

### What You Get

- `web3gig` CLI tool (Python)
- 24+ job listings (updated monthly)
- 8 grant program listings
- 4 audit contest listings
- Cover letter templates
