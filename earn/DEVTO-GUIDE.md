# dev.to Publishing Guide — QUANTA Articles

## Setup Account
1. Go to https://dev.to
2. Click "Create Account"
3. Sign up with GitHub or Twitter

## How to Publish

### Format for dev.to
dev.to uses Markdown with YAML frontmatter. Add this to each article:

```yaml
---
title: "Article Title Here"
published: true
description: "Meta description here"
tags: web3, solidity, blockchain
canonical_url: https://hackernoon.com/original-article-url
---
```
